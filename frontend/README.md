# Frontend

React 18 + TypeScript SPA for the Event Analytics dashboard.

See the root [README](../README.md) for architecture, env vars, and API docs.

```bash
npm install
npm run dev    # http://localhost:5173, proxies /api to :8000
npm run test   # vitest
npm run lint   # oxlint
npm run build  # type-check + production build to dist/
```
